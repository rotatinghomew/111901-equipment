# 公益健身器材报障分类与抽核结果应用

本项目围绕社区全民健身公共服务的本地分析资料。数据均为合成记录，文件字段与时间口径按各自数据文件表示。项目目录包含业务资料、分析软件包和基础数据检查。

## 环境与运行

需要 Python 3.11 或更新版本，无第三方运行依赖。

```bash
# 检查合成资料与全部业务规则测试
python -m unittest discover -s tests -v

# 端到端分析（输出结构化 JSON；隔离模式下用 sys.path 注入包路径）
python -I -c "import sys; sys.path.insert(0, 'src'); \
from equipment.cli import main; main(['--data-dir','data','--holdout','f5'])"
```

分析包位于 `src/equipment`，可从 Python 导入。输入资料位于 `data/`，CSV 使用 UTF-8 编码和首行字段名，策略资料采用 JSON（`data/policy/`）。

## 数据约定

所有居民、机构、地点与活动均为虚构标识，时间以数据字段的本地日期表示。空字段表示该资料没有登记值，不应据此推断业务事实；具体数据口径以相应字段和 JSON 政策文件为准。资料用于离线分析，不含外部服务或凭据，**系统不做任何远程设备操作**。

## 分析包结构与业务规则

| 模块 | 职责 |
|---|---|
| `io.py` / `models.py` | CSV/JSON 只读加载、空值与日期处理、引用完整性校验 |
| `taxonomy.py` | 分类口径版本化；按描述发生日期适用当时版本；老标签经 lineage 解释，新细类不硬拆历史标签 |
| `classify.py` | 规则化识别故障类别、不确定项（疑似/待复查）、影响服务程度、催问件；每条结论附判断凭据，无规则命中时弃权 |
| `identity.py` | 依迁移链归并物理设备；多编号声称同一旧编号时关系冻结不合并；同型号共址无迁移凭据不合并 |
| `events.py` | 以**已核实修复生效日**为硬边界划分事件；催问与同类别描述作为重复反映挂载；类别冲突只建疑似关联，不进官方统计 |
| `quality.py` | 时间后移切片（同事件整体同侧、单号/事件号零重叠）+ 型号留出；错误率与未判定（弃权）率分测；成对合单精确率/召回率；Wilson 区间 |
| `review.py` | 风险派发与轮换抽样双轨；名额按地点×技能扣除已约人员；疑似安全故障强制现场、名额不足即升级，不得标记可继续开放；仅入样机会可知的轮换样本可做 Horvitz–Thompson 外推 |
| `planning.py` | 巡查台账只追加不改写，已核销时数按当时任务保留；复核确认修后新事件时重审待巡清单、重复故障率与同型号观察范围，并列出被替换的弱证据；提供主管视图 |
| `pipeline.py` / `cli.py` | 端到端编排与命令行输出 |

### 关键口径

1. **类别换版**：`taxonomy.json` 中 v1（c0–c4 五类）与 v2（增加 c1.1 等细类）按生效日期切换；历史标签只做父类/同义映射并保留解释，不反向猜测细类。
2. **事件归属四要素**：物理设备（迁移链确认后）、发生时间（核实修复边界切窗）、部件（类别一致才确认合单）、修复生效状态（pending 不构成边界）。未确认关系保持 `provisional`，与已确认统计分账。
3. **学习/验收隔离**：同一事件及近似重复件整体进入训练侧或验收侧；时间靠后的故障衡量错误，训练未覆盖型号上分类器强制弃权，弃权率单独衡量未判定范围。
4. **抽核双轨**：风险轨按误分后果、安全疑似、未覆盖型号、催问量加权，入样机会未知，结论不可外推、不可直接排班；轮换轨按型号分层随机并记录每层入样机会 π，是唯一可外推总体错误率的样本。
5. **复核回写**：历史巡查任务不可覆盖，仅登记替换指针；新安排必须说明哪些 pending 处置、疑似关联、未判定描述等弱证据已被现场结论替换。

## 测试

`tests/` 下除原有资料完整性检查外，按模块覆盖：口径版本与凭据、迁移身份歧义、修复边界与疑似合单、时间切片/型号留出/防泄漏、名额约束与安全升级、台账不可变与主管视图，以及 CLI 结构化输出。
